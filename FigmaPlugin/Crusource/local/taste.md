# Visual Taste & Design Preferences — Crusource Desktop

> Visual layout and design language for Crusource Desktop SaaS UI.

---

## 🎨 Overall Design Language

- **Visual Style:** Modern B2B SaaS Dashboard, enterprise clean, high data density, structured grid
- **Canvas Size:** `1440px × 900px` Desktop Viewport
- **Density:** Professional Enterprise (comfortable paddings: 16px - 24px)
- **Color Accent:** Crusource Orange (`#FF7700`) accenting key CTAs, active nav item indicators, and status metrics

---

## 📐 Desktop Architecture & Corner Radius

| Token | Value | Primary Application |
|:------|:------|:-------------------|
| `radius-xs` | **4px** | Badges, status pills |
| `radius-sm` | **6px** | Buttons, input search bar, table header cells |
| `radius-md` | **8px** | Metric cards, action widgets |
| `radius-lg` | **12px** | Main panel containers, table containers |
| `radius-xl` | **16px** | Hero overview cards |

---

## 🌫️ Shadow & Elevation System

- **Card Border + Lift:** `1px solid #E2E8F0` with subtle shadow `0 1px 3px rgba(15, 23, 42, 0.04)`
- **Dropdown / Overlay:** `0 10px 15px -3px rgba(15, 23, 42, 0.08)`
- **Active Navigation Item:** Left border accent line `#FF7700` (4px width) with soft `#FFF0E6` background fill.
